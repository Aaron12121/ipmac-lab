# IP 与 MAC 地址交互教学模型

[打开模型](https://aaron12121.github.io/ipmac-lab/)

面向课堂的可调参数可视化模型，展示 ARP、IP 数据报封装、路由器逐跳转发与重新封装，以及附近探针的被动监听。

## 使用

选择目的设备，点击“连续播放”或逐步演示。去程完成后可按需触发回包；底部四地址条同步显示源 IP、目的 IP、源 MAC、目的 MAC。参数面板可调整网络条件。

默认手机 IP 为 `192.168.1.88/24`，网关为 `192.168.1.1`；收银终端为 `192.168.1.20`，远端服务器为 `203.0.113.10`。

`index.html` 包含完整 HTML、CSS 和 JavaScript，无需安装依赖。下载后用浏览器打开即可离线使用。GitHub Pages 从 `main` 分支根目录发布。

## 教学边界

- 动画时间用于教学，不代表网络实测时延。
- 模型不包含 NAT 或 Proxy ARP，合并表示 AP 内部转发。
- 四地址条表示教学中的两个 IP 地址与两个链路层地址，不等同于 IEEE 802.11 的四个 MAC 地址字段。
- 探针被动监听无线环境，不参与正常转发；无线加密且没有密钥时，不能据此读取 ARP/IP 内容。
