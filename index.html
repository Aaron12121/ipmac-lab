模型说明

先选择目的地址，再点击“下一步”或“连续播放”。去程交付完成后，点击“发送回包”。可暂停观察，也可打开“调参”验证错误配置。

哪些内容做了简化？

本模型按课件展示逻辑链路交付，不模拟 NAT、DNS、DHCP、拥塞或链路丢包。图中的网关包含接入功能；同一 Wi-Fi 内终端间的 AP 转发过程合并显示。

“四个地址”指两种 IP 与两种 MAC，并不是 802.11 的四个 MAC 地址字段。实际 Wi-Fi 帧还可能带有 BSSID / 收发接口等地址。ARP 不封装在 IP 数据报中，其 IP 字段表示发送方与目标协议地址。

探针的观察条件

假设探针位于覆盖范围内、监听相同信道且没有解密密钥。它能读取无线 MAC 首部；加密时不能读取帧体内的 IP 或 ARP 内容。开放 Wi-Fi 可暴露 IP，但不表示 HTTPS 应用内容也可读。探针不会阻断、转发或应答报文。

随机 MAC 开关仅比较链路标识，不模拟随机地址更换周期。缓存预热只影响已知邻居；回包可复用去程 ARP 学到的映射。封装动画省略部分控制字段，未计算 FCS；动画时长不代表真实网络时延。
